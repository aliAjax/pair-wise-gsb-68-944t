# 新闻事实核查证据链与发布审阅工作台

基于React、Chakra UI、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。数据使用浏览器本地持久化。

## 功能

- 核查主张列表、搜索、状态筛选和新建。
- 可验证事实树、支持证据、相反证据、置信度和未解决疑点。
- 原始证据、二次来源、待证信息分类与内容哈希留档。
- 证据关系图、来源时间线、多人批注和解决状态。
- 发布前校验、版本记录、完整档案与审计导出。

### 来源—结论—发布版本联动

- **来源撤下/换版**：在证据卡片上登记改动，旧来源只追加修订留痕（哈希与内容不覆盖）；换版会自动挂接新版本来源并标记接替关系。
- **结论失效传播**：所有依赖该来源的事实结论（支持或相反证据）立即置为「失效待确认」并锁定编辑，未受影响的事实继续可用。
- **编辑重新确认**：编辑核对后改判并追加确认记录（含当时来源快照），事实恢复可用；审计只追加。
- **发布版本快照**：发布即另存新版本，冻结每项事实的来源哈希/版本/状态；旧版本永久保留当时快照、照旧可引用，重新确认前不能再次发布或导出。
- **可恢复写入**：发布与失效传播按步骤落库；写入失败保留已完成步骤，页面标出当前阻断点，重试只补未完成部分（侧边栏可注入下一次写入失败演示）。
