# 新闻事实核查证据链与发布审阅工作台

基于React、Chakra UI、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。数据使用浏览器本地持久化。

## 功能

- 核查主张列表、搜索、状态筛选和新建。
- 可验证事实树、支持证据、相反证据、置信度和未解决疑点。
- 原始证据、二次来源、待证信息分类与内容哈希留档。
- 证据关系图、来源时间线、多人批注和解决状态。
- **来源生命周期联动**：来源撤下或换版后，引用它（含相反证据）的事实结论立即失效并等待编辑重新确认，未受影响事实继续可用；来源时间线保留旧版与新版指向。
- **不可变发布版本**：发布即冻结当时完整快照（主张+来源+哈希），编辑核对后只能另存新版本；旧版与审计只追加。存在待重新确认事实时阻断再次发布、档案导出和快照导出，历史版本仍可查看并标注“快照后来源已变动”。
- **多步写入与断点续跑**：来源变动（登记→失效→审计）、重新确认（恢复→审计）、发布（校验快照→审计）均为分步任务；写入在任一步中断后保留已完成项，重试只补未完成步骤，列表、工作台、侧边栏标出当前阻断点。侧边栏“写入故障演练”开关可确定性触发中断。
- 发布前校验、版本记录、完整档案与审计导出。
